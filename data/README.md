# Primary data inventory (access/terms must be rechecked on ingestion)
- Broad DepMap/Achilles single-gene Chronos effect + CCLE molecular features and model metadata, official portal https://depmap.org/portal/ and release notes https://forum.depmap.org/t/announcing-the-25q3-release/4476 . Portal currently presents a bot verification screen through web fetch; it says bulk data belong in downloads, not scraped. File-level access, redistribution license and checksums unverified. Single-gene screen cannot directly validate a pair/triple.
- Sanger Cancer Dependency Map single-gene CRISPR data https://depmap.sanger.ac.uk/documentation/datasets/wg-crispr-knockout/ and use policy https://depmap.sanger.ac.uk/documentation/data-usage-policy/ . Data files allow internal research/education; resale or significant-part commercial services excluded. API non-commercial without registration, rate limited; do not republish raw bulk data into GitHub or Drive without checking terms.
- Harle et al. 2025 independent dual-guide screening https://link.springer.com/article/10.1186/s13059-025-03737-w : 472 proposed gene pairs, 27 cancer lines (melanoma/pancreatic/lung), NOT HGSOC; cannot count it as HGSOC validation. Article text says code/notebooks on GitHub and Zenodo; confirm raw screen accession and use terms before ingestion.
- SynLethDB https://www.synlethdb.com/download : documented experimentally reported human SL and non-SL pair lists plus computational predictions. Prediction file must NEVER count as measured positive. Download terms unresolved.
- Zhou et al., Cell Reports 2020 https://www.cell.com/cell-reports/fulltext/S2211-1247(20)31005-6 : high-order combinatorial perturbation screen in OVCAR8-ADR ovarian line with triple, double and single followups. Verify accession/raw values and held-out independence before using; a published hit cannot be called new. Existing screen targets druggable genes, not necessarily DNA-repair candidates; overlap uncertain.
- TCGA/GDC PanCancer DDR study https://gdc.cancer.gov/about-data/publications/PanCan-DDR-2018 : open access manifests and controlled-access distinction; patient genomics can contextualize mechanisms but is not an experimental knockout test.
- BioGRID ORCS https://orcs.thebiogrid.org/ : public screening directory; accession-level datasets must each be ingested and deduplicated to count. Data-use terms and applicable ovarian paired perturbation sources need auditing.
- Normal comparator remains unverified: GTEx expression is not healthy knockout viability. Do not claim selective lethality without proper measurement.

No primary outcome data ingested or analyzed at preregistration. No data count credit, tool-execution credit or biological discovery yet.
- Verified source directory for Zhou et al. 2020 accession GSE154112: https://ftp.ncbi.nlm.nih.gov/geo/series/GSE154nnn/GSE154112/suppl/ lists ovarian two-way gRNA count-per-million workbook (2.7 MB), three-way ovarian workbook (3.6 MB), OVCAR8-ADR RNA-seq raw-count file (635 KB), and unrelated Parkinson's two-way workbook. Directory listing only, NOT readouts inspected, accession not ingested/countable. File-level license should be confirmed. The triple screen remains only one ovarian cancer model, and exact target overlap with preregistered DNA repair unknown.
- GEO accession GSE262953 https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE262953 has paired knockout targeted count files with triplicate initial/final samples; paper context/cell model and independence need scrutiny. Metadata alone is not a screen validation.
- Broad DepMap updated terms correction: official project forum statement dated 2026-07-28 https://forum.depmap.org/t/provide-an-open-endpoint-for-latest-version-retrieval/4652 quotes research/internal ML and non-profit research sharing permitted, commercial incorporation or AI model sale requires separate license. This differs from older Broad CC BY statements; file-specific terms remain authoritative. Its official https://depmap.org/portal/api/no-captcha/download/files returns metadata, checksums and latest release listing, BUT deliberately no file URLs, not a raw-download mechanism. 26Q1 https://forum.depmap.org/t/announcing-the-26q1-release/4606 supersedes 25Q3 for default development planning; 26Q3 status has not been confirmed. Avoid high-volume/scraping downloads through portal; browser-authenticated download only when permitted.
- 2026-09-26 GEO GSE154112 workbooks inspected locally, raw data NOT committed: 3-way file SHA256 b54507687f8f5d945eac15c6452cdc3a85bf2faee7ed14f126268c8fd656d889, 2-way SHA256 54654f48827e534aa8e8bc923427f0e76c576f769ab8df6b756db3a1520b012c. Three-way workbook 32768 guide combinations, two guides per each of 15 targeted genes and two dummy guides. Targets: CDK4, DNMT1, EGFR, ERBB2, HDAC1, IKBKB, MAP2K1, MTOR, POLA1, TOP1, TUBA1A, TYMS, FGF2, PIK3C3, TGFB1. Limited overlap with DNA repair and exactly one ovarian model OVCAR8-ADR; gRNA normalized sequencing counts are not cell viability assays or a healthy cell comparator. Do not take number of guides or combinations as accession-level datasets. One public GEO series ingested for source-schema inventory, ZERO outcome-evaluable datasets yet.
- Historical SynLethDB 2020 official team dataset https://github.com/JieZheng-ShanghaiTech/SynLethDB/tree/master/synlethdb_dataset_2020/sl : Human_SL.csv SHA256 d63d4c602b281b9ef2a1ebcbd09990a9f7588f61efa547cc8b799c5437da0d0b, 36,746 gene-pair rows; source labels mix CRISPR, RNAi, text mining and computational-only predictions. SL.cellline is literal 'null' for all rows in this CSV, so no HGSOC-specific verification possible; use as conservative exclusion registry ONLY, not as experimental labels. Dataset team repo states all rights reserved and requests citations; no redistribution of its raw CSV into this repo/Drive. Since 2020, papers have added many interactions; registry miss is not proof of novelty.

- SCHEMATIC 2024 https://www.nature.com/articles/s41588-024-01971-9 : independent double knockout 67 x 176 gene-pair design in seven cancer lines, raw SRA accession PRJNA701256 and counts in publisher Supplementary Data 1/2. The published result registry includes 1,805 SL interactions (95% then-unreported), so cannot reuse as novelty. Seven cell-line identities not yet verified; do not assume HGSOC.
- GSE262953 https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE262953 : paper source https://pmc.ncbi.nlm.nih.gov/articles/PMC11361842/ clarifies paired screen is prostate 22Rv1, NOT ovarian/HGSOC; remove it from HGSOC validation candidates.
- Cell identity: OVCAR-8 is listed as high-grade ovarian serous adenocarcinoma in https://www.cellosaurus.org/CVCL_1629 ; GSE154112 used drug-resistant OVCAR8-ADR derivative and must not be generalized to all HGSOC without additional models. See model suitability cautions https://www.nature.com/articles/ncomms3126 .
- SCHEMATIC correction after primary Supplementary Data 1/2 download (publisher links exposed at https://www.nature.com/articles/s41588-024-01971-9 ): actual seven cell lines MCF7, MDAMB231, MCF10A, CAL27, CAL33, A549, A427. ZERO HGSOC. MCF10A non-tumorigenic breast line cannot serve as a matched normal ovarian/fallopian comparator. Raw Data 1 is 28.2 MB time-course read-count matrix; Data 2 workbook ~6.5 MB pair effect scores and FDR. No HGSOC validation credit. Source file hashes if reusing must be logged; raw data not in repo.
