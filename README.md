# HGSOC synthetic-lethal RL
Computational discovery of DNA-repair genetic interactions, with RL as a search component and independent perturbation evidence as the gate. Preregistration: [docs/PREREGISTRATION.md](docs/PREREGISTRATION.md). Data inventory: [data/README.md](data/README.md). A synthetic-fixture policy-gradient scaffold and 12 unit tests exist, but no biological result or candidate is claimed yet.
