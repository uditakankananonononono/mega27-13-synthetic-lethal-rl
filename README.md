# HGSOC synthetic-lethal RL
Computational discovery of DNA-repair genetic interactions, with RL as a search component and independent perturbation evidence as the gate. Preregistration: [docs/PREREGISTRATION.md](docs/PREREGISTRATION.md). Data inventory: [data/README.md](data/README.md). A synthetic-fixture policy-gradient scaffold and 74 unit tests (26 test files) exist. Several negative or null development results are recorded in `docs/` and `results/` (e.g. GSE154112: 0 of 455 evaluable triples at BH q<0.05; see `docs/GSE154112-NEGATIVE.md`, `docs/EVIDENCE-GATE-LEDGER.md`). No biological result or candidate is claimed yet.
