# Exploratory assay plan: GSE154112, 2026-09-26
This is NOT an amendment to locked preregistration: the HGSOC generalization/healthy viability gate remains publicly data-blocked. The present plan is frozen before analyzing any experimental effect values. Cell model OVCAR8-ADR, 15 target genes, pooled guide counts at D9/D15/D26; this is a single cell-line assay with two D26 replicates. Target list and source schema were inspected before writing this exploratory plan. No result values have been tested.

For each three-guide construct, calculate log2((D26 CPM+1)/(D9 CPM+1)) separately for D26 replicate 1 and 2. A no-target triple dummy construct is a reference. For a target triple A/B/C, compare that target set with all double-target+dummy and single-target+double-dummy constructs. Approximate third-order excess interaction for replicate r:
E_ABC,r - E_AB,r - E_AC,r - E_BC,r + E_A,r + E_B,r + E_C,r - E_0,r.
Each E is the median per-replicate log2 fold-change of distinct guide constructs in the same three-position library. This controls library dimension but not guide efficiency, position, barcode effects, or biological variation. No zero-imputation: if any subset absent, mark untestable. Prefer triplets with >=4 unique constructs for each required subset. Report all 455 distinct gene triples, assay subset coverage, replicate concordance, and observed controls. Bootstrap guide constructs within each subset 1,000 times with seed 20260926, separately for each replicate; paired midpoint estimates and confidence bounds are exploratory because biological replicate count is only 2. BH FDR may be calculated but is not a substitute for independent biological validation. Do not define a 'triple synthetic lethal hit' from CPM alone, and do not identify a candidate as previously unrecognized based on database absence alone. Source files are not to be published without rights check.

Positive controls: reported published triplets if present; no claim of novelty for them. Negative controls: randomly permuted gene labels preserving subset-size distribution and gene essentiality matched to repair membership where feasible. The simple no-RL baseline is the strongest matched search budget; policy is not trained on this assay. Any exploratory prioritization is held separately until a development-only surrogate exists.
