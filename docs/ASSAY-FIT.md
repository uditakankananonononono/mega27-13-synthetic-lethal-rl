# Assay fit and honest limitation, 2026-09-26
The pre-registered HGSOC DNA-repair project requires independent measurements for rare pair/triple targets and matched healthy-cell perturbation effects. The available GSE154112 ovarian combinatorial screen is useful but covers only 15 targeted genes, of which POLA1, TOP1 and TYMS have plausible replication/metabolism relevance. It is not a genome-wide experimental search; the external screen only tests in-library nominations and does not make out-of-library candidates experimentally supported. RNA-seq from the same model is not an independent viability replication. Three-way gRNA counts with D9, D15, D26 rep1/rep2 can support a modeled growth-depletion interaction after control/guide QC, not the originally described categorical single/pair-survive/triple-dies phenotype without calibrated measured viability. Healthy selective effect cannot be claimed until a matched nonmalignant perturbation source is found. This limits interpretation before any score calculation. Sources: https://www.cell.com/cell-reports/fulltext/S2211-1247(20)31005-6 and https://ftp.ncbi.nlm.nih.gov/geo/series/GSE154nnn/GSE154112/suppl/ .
