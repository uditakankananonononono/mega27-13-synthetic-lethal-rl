Initial deterministic fit: source score matrix 318 models by 17,799 genes; 349 of 366 Reactome DNA Repair gene IDs overlap, then repair-first 2,000-gene selection; 28 OVARY-named training models after holding KURAMOCHI ACH-000524 aside. Raw co-pathway graph has 99,269 edges after suppressing broad pathway cliques above 80 members. This is a development convenience filter, NOT subtype-verified HGSOC. CERES-derived clipped negative effect maps to an arbitrary log-loss proxy, not measured viability. Pair/triple interaction prior is bounded at 0.1/0.05 and uncertainty increases with perturbation order; neither is learned from paired assays. Normal-cell viability is wholly absent, so no cancer-selective RL reward or claim.

Possible better subtype filter before scored training: verify each model through official source annotations rather than name suffix; source list includes OVCAR8 parental and KURAMOCHI but also other histotypes, and OVCAR8-ADR independent screen is a drug-resistant derivative. No actual policy-versus-baseline comparison or held-out fit score has been reported. Next QC is subtype membership + heldout monogenic calibration, before any external combinatorial assay use.
