# Histotype-verified development subset of historical SCORE (2026-09-26)
The 2019 Sanger Project SCORE monogenic matrix contains 29 models whose Broad naming.csv labels end `_OVARY`. That suffix is tissue, not histotype. Source audit queried the Cellosaurus read-only API https://api.cellosaurus.org/ using exact primary-name/synonym matching, recording accession and Disease labels for all 29 rows in `results/historical-ovarian-cellosaurus-identity.json`. The script `scripts/cellosaurus_histotype_audit.py` reproduces the lookup. Disease labels are an external identity classification, not direct pathology adjudication, and might change. The raw SCORE matrix is not distributed in this repository.

Ten unique exact Cellosaurus matches have the explicit Disease label "High grade ovarian serous adenocarcinoma": NIHOVCAR3 (`ACH-000001`, https://www.cellosaurus.org/CVCL_0465), CAOV4 (`ACH-000103`, https://www.cellosaurus.org/CVCL_0202), JHOS2 (`ACH-000132`, https://www.cellosaurus.org/CVCL_4647), TYKNU (`ACH-000430`, https://www.cellosaurus.org/CVCL_1776), KURAMOCHI (`ACH-000524`, https://www.cellosaurus.org/CVCL_1345), JHOS4 (`ACH-000584`, https://www.cellosaurus.org/CVCL_4649), OVCAR8 (`ACH-000696`, https://www.cellosaurus.org/CVCL_1629), OVCAR5 (`ACH-001151`, https://www.cellosaurus.org/CVCL_1628), HEY (`ACH-002140`, https://www.cellosaurus.org/CVCL_0297), OVMIU (`ACH-002183`, https://www.cellosaurus.org/CVCL_3112). KURAMOCHI and OVCAR8 are held out, leaving eight explicit-HGSOC development models. The same 2,000-gene monogenic builder with `allowed_models` restricted to these identities runs successfully with 349 repair actions and 99,269 network co-membership edges. This is a finite, small, subtype-filtered *monogenic* development matrix, not trained pair/triple interactions.

The other 19 lack the exact explicit high-grade serous Disease label in this API audit or have ambiguous identity. Some serous/cystadenocarcinoma and hereditary-BRCA labels may have supporting histology in other papers but do not pass this conservative evidence rule. ES2_OVARY matches multiple normalized aliases, including an Ewing sarcoma ES2 and ovarian clear-cell ES-2, and stays excluded without a stable accession binding. OVISE, TOV112D, A2780, MCAS, TOV21G and others are explicitly other histotypes. Source caution on subtype mismatch https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0072162 . The old 25-model cancer-only surrogate and five-control comparison used mixed ovarian histotypes and remain transparently labeled; no post-hoc replacement of those historical results.
